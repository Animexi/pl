# LiteAuth - Система авторизации для Minecraft PE 1.1.5

## Описание

LiteAuth - это полноценный плагин авторизации для Minecraft Pocket Edition 1.1.5 на ядре LiteCore. Плагин предоставляет систему регистрации, авторизации, капчи, авто-логина и защиты аккаунтов.

## Установка

1. Скопируйте папку `LiteAuth` в директорию `plugins/` вашего сервера
2. Запустите сервер - файлы конфигурации создадутся автоматически
3. Настройте `config.yml` и `messages.yml` по вашему усмотрению
4. Перезапустите сервер или выполните `/auth reload`

## Команды

### Игровые команды

| Команда | Описание | Алиасы |
|---------|----------|--------|
| `/register <пароль> <пароль>` | Регистрация нового аккаунта | `/reg` |
| `/login <пароль>` | Вход в аккаунт | `/l` |
| `/captcha <ответ>` | Ответ на капчу | - |
| `/auth` | Информация об аккаунте | - |

### Административные команды

| Команда | Описание | Permission |
|---------|----------|------------|
| `/auth info <игрок>` | Показать информацию об игроке | `liteauth.info` |
| `/auth unregister <игрок>` | Удалить аккаунт игрока | `liteauth.unregister` |
| `/auth logout <игрок>` | Вывести игрока из аккаунта | `liteauth.admin` |
| `/auth reload` | Перезагрузить конфигурацию | `liteauth.reload` |

## Permissions

| Permission | Описание | По умолчанию |
|------------|----------|--------------|
| `liteauth.admin` | Доступ к админ-командам | Op |
| `liteauth.bypass` | Обход авторизации | Op |
| `liteauth.reload` | Перезагрузка конфига | Op |
| `liteauth.unregister` | Удаление аккаунтов | Op |
| `liteauth.info` | Просмотр информации | Op |

## Конфигурация

### config.yml

```yaml
# Настройки пароля
min-password-length: 6
max-password-length: 32

# Таймаут авторизации (секунды)
auth-timeout: 60

# Лимит попыток входа
max-login-attempts: 5
login-delay: 3

# Настройки капчи
captcha-enabled: true
captcha-attempts: 3
captcha-timeout: 120

# Авто-логин
auto-login: true
session-time: 86400
session-by-ip: false

# Регистрация
registration-enabled: true
max-registrations-per-ip: 3

# Кик при таймауте
kick-on-timeout: true

# Чёрный список паролей
password-blacklist:
  - "123456"
  - "password"
  - "qwerty"

# Отладка
debug: false
```

## Особенности

### Безопасность

- Хеширование паролей (password_hash или SHA-256)
- Защита от перебора паролей
- Ограничение регистраций с одного IP
- Капча после регистрации
- Сессии с таймаутом

### Блокировки до авторизации

- Движение заблокировано
- Чат заблокирован
- Команды заблокированы (кроме /login, /register, /captcha)
- Взаимодействие с блоками заблокировано
- Атаки заблокированы
- Выбрасывание предметов заблокировано

### Авто-логин

При включённом авто-логине игрок автоматически авторизуется при повторном входе на сервер (в течение срока действия сессии).

## Сообщения

Все сообщения настраиваются в `messages.yml`. Поддерживаются переменные:
- `{player}` - имя игрока
- `{prefix}` - префикс плагина
- `{attempts}` - количество попыток
- `{max_attempts}` - максимальное количество попыток
- `{captcha}` - текст капчи
- `{status}` - статус аккаунта
- `{session}` - статус сессии
- `{autologin}` - статус авто-логина

## Дизайн

Плагин использует единый визуальный стиль:
- Префикс: `§e§lLITE§f§lAUTH §8┃`
- Цвета: жёлтый (§e), белый (§f), серый (§7, §8)
- Рамки для важных сообщений
- Без эмодзи и Unicode-символов

## Логи

Плагин ведёт логирование всех важных событий:
- Регистрация игроков
- Успешный вход
- Неудачные попытки входа
- Блокировки
- Действия администраторов

Пароли никогда не записываются в логи.

## Совместимость

- Minecraft PE 1.1.5
- Ядро: LiteCore / PocketMine-MP API 3.0.0-3.0.2
- PHP 7.2+

## Известные ограничения

- UUID игроков может быть недоступен в старых версиях
- Некоторые современные функции PocketMine отсутствуют
- Максимальная длина ника ограничена клиентом

## Поддержка

При возникновении проблем проверьте:
1. Версию ядра сервера
2. Версию PHP
3. Логи сервера
4. Настройки конфигурации

## Лицензия

Свободное использование для любых серверов Minecraft PE.
