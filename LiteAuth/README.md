# LiteAuth - Плагин авторизации для Minecraft PE 1.1.5

## Описание

LiteAuth — полноценный production-ready плагин авторизации для Minecraft Pocket Edition 1.1.5, работающий на ядре LiteCore.

### Возможности:
- ✅ Регистрация аккаунтов
- ✅ Авторизация
- ✅ Мини-капча (математические примеры)
- ✅ Авто-логин по сессии
- ✅ Защита от перебора паролей
- ✅ Блокировка действий до авторизации
- ✅ Управление сессиями
- ✅ Административные команды
- ✅ Единый дизайн сообщений (жёлто-белая тема)
- ✅ Подробное логирование
- ✅ Настройка через config.yml и messages.yml

---

## Установка

1. Скопируйте папку `LiteAuth` в директорию `plugins/` вашего сервера
2. Запустите сервер — плагины создаст файлы конфигурации
3. При необходимости настройте `config.yml` и `messages.yml`
4. Перезапустите сервер или выполните `/auth reload`

## Команды

| Команда | Описание | Permission |
|---------|----------|------------|
| `/register <пароль> <пароль>` | Регистрация нового аккаунта | - |
| `/reg <пароль> <пароль>` | Короткая версия регистрации | - |
| `/login <пароль>` | Вход в аккаунт | - |
| `/l <пароль>` | Короткая версия входа | - |
| `/captcha <ответ>` | Ответ на капчу | - |
| `/auth info <player>` | Информация об аккаунте | liteauth.admin |
| `/auth unregister <player>` | Удалить аккаунт | liteauth.admin |
| `/auth changepassword <player> <password>` | Сменить пароль | liteauth.admin |
| `/auth logout <player>` | Выйти из аккаунта | liteauth.admin |
| `/auth reload` | Перезагрузить конфигурацию | liteauth.admin |

## Конфигурация (config.yml)

```yaml
# Длина пароля
min-password-length: 6
max-password-length: 32

# Таймауты (секунды)
auth-timeout: 60
captcha-timeout: 60

# Безопасность
max-login-attempts: 5
captcha-enabled: true
captcha-attempts: 3

# Сессии
auto-login: true
session-time: 86400
session-by-ip: false

# Регистрация
registration-enabled: true
max-registrations-per-ip: 3

# Kick при таймауте
kick-on-timeout: true

# Запрещённые пароли
password-blacklist:
  - "123456"
  - "password"
  - "qwerty"

# Отладка
debug: false
```

## Дизайн сообщений

Все сообщения используют единую визуальную систему:
- **§e** — золотой/жёлтый (заголовки, команды)
- **§f** — белый (основной текст)
- **§7** — серый (второстепенная информация)
- **§8** — тёмно-серый (разделители)
- **§c** — красный (ошибки)
- **§a** — зелёный (успех)
- **§l** — жирный (важные элементы)

Префикс всех сообщений: `§e§lLITE§f§lAUTH §8┃`

## Архитектура

### Состояния игрока:
1. **UNREGISTERED** — игрок не зарегистрирован
2. **REGISTERED** — зарегистрирован, требуется капча
3. **CAPTCHA** — проходит капчу
4. **AUTH_REQUIRED** — требуется ввод пароля
5. **AUTHENTICATED** — полностью авторизован

### Компоненты:
- **LiteAuthPlugin** — главный класс, загрузка, регистрация команд и слушателей
- **AuthManager** — управление состояниями, регистрация, вход, капча, сессии
- **YamlStorage** — хранение данных игроков в YAML-файлах
- **Commands** — обработка команд игрока
- **Listeners** — блокировка действий до авторизации

## Ограничения Minecraft PE 1.1.5 / LiteCore

1. **API**: Используется старый API PocketMine-MP 3.x, совместимый с LiteCore
2. **PHP**: Код написан для PHP 7.0-7.2 без современных конструкций
3. **Хеширование**: password_hash/password_verify доступны в PHP 7.0+
4. **События**: Используются базовые события PlayerJoinEvent, PlayerMoveEvent и др.
5. **Location**: Конструктор требует точного порядка аргументов (x, y, z, yaw, pitch, level)
6. **Команды**: Метод execute должен возвращать bool и иметь правильную сигнатуру
7. **Нет UUID**: Используется нормализованное имя игрока как ключ

## Безопасность

- Пароли хранятся только в хешированном виде (bcrypt)
- Никогда не записываются в логи, чат или консоль
- Защита от brute-force (лимит попыток)
- Защита от спама командами
- Ограничение регистраций с одного IP
- Капча для защиты от ботов
- Сессии с ограниченным сроком жизни
- Проверка сложных паролей (чёрный список)

---

## Логи

Плагин записывает в консоль:
- Успешную регистрацию
- Успешный вход
- Неудачные попытки входа
- Действия администраторов
- Перезагрузку конфигурации

Пароли никогда не записываются в логи.

## Поддержка

При возникновении проблем:
1. Проверьте версию ядра (требуется LiteCore / PMMP 3.x)
2. Включите debug: true в config.yml
3. Проверьте права доступа к папке plugins/LiteAuth
4. Убедитесь, что PHP версии 7.0+
