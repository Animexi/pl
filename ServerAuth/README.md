# ServerAuth - Плагин регистрации и авторизации для PocketMine-MP

## Описание
Полноценный production-ready плагин для регистрации, авторизации и защиты игроков на серверах Minecraft PE (PocketMine-MP).

## Требования
- **PocketMine-MP**: API 3.0.0 - 4.0.0 (MCPE 1.1.5)
- **PHP**: 7.2+
- **Minecraft PE**: 1.1.5

## Установка

### Автоматическая установка
1. Скачайте файл `ServerAuth.phar`
2. Поместите его в папку `plugins/` вашего сервера
3. Перезапустите сервер

### Ручная сборка
```bash
# Создание phar-архива
php -dphar.readonly=0 build.php
```

Или просто скопируйте папку `src/` и файлы ресурсов в папку плагина.

## Настройка

### config.yml
```yaml
# Префикс сообщений
prefix: "§8[§6Server§8]"

# Безопасность
security:
  max_login_attempts: 5      # Максимум попыток входа
  login_cooldown: 3          # Cooldown между попытками (сек)
  lock_time: 300             # Время блокировки (сек)
  min_password_length: 4     # Мин. длина пароля
  max_password_length: 20    # Макс. длина пароля

# Защита
protection:
  move: true                 # Блокировка движения
  interact: true             # Блокировка взаимодействия
  block_break: true          # Блокировка разрушения блоков
  block_place: true          # Блокировка установки блоков
  damage: true               # Блокировка урона
  drop_item: true            # Блокировка выброса предметов

# Разрешённые команды до авторизации
allowed_commands:
  - "login"
  - "register"
  - "changepassword"
  - "auth"
```

### messages.yml
Все сообщения плагина находятся в `messages.yml`. Поддерживаются цвета:
- `§8` - тёмно-серый
- `§7` - серый
- `§f` - белый
- `§6` - золотой
- `§a` - зелёный (успех)
- `§c` - красный (ошибка)
- `§e` - жёлтый (предупреждение)

## Команды

### Игровые команды
| Команда | Описание | Permission |
|---------|----------|------------|
| `/register <пароль> <повтор>` | Регистрация нового аккаунта | serverauth.register |
| `/login <пароль>` | Вход в аккаунт | serverauth.login |
| `/changepassword <старый> <новый>` | Смена пароля | serverauth.changepassword |

### Административные команды
| Команда | Описание | Permission |
|---------|----------|------------|
| `/auth reload` | Перезагрузка конфигурации | serverauth.reload |
| `/auth unregister <игрок>` | Удаление аккаунта | serverauth.unregister |
| `/auth info <игрок>` | Информация об аккаунте | serverauth.info |

## Permissions

```yaml
serverauth.admin:        # Полный доступ (default: op)
serverauth.reload:       # Перезагрузка конфигурации
serverauth.unregister:   # Удаление аккаунтов
serverauth.info:         # Просмотр информации
serverauth.register:     # Регистрация (все игроки)
serverauth.login:        # Вход (все игроки)
serverauth.changepassword: # Смена пароля (все игроки)
```

## Состояния игрока

1. **UNREGISTERED** - игрок не зарегистрирован
   - Доступны только `/register`
   - Все действия заблокированы

2. **REGISTERED_NOT_LOGGED** - зарегистрирован, не авторизован
   - Доступен только `/login`
   - Все действия заблокированы

3. **LOGGED_IN** - авторизован
   - Полный доступ к серверу

## Безопасность

- **SHA-256 хеширование** паролей с уникальной солью
- **Защита от перебора**: блокировка после 5 неудачных попыток
- **Cooldown**: 3 секунды между попытками входа
- **UUID привязка**: аккаунт привязан к UUID игрока
- **Автоматический logout**: при выходе из игры

## Хранение данных

Данные хранятся в `plugins/ServerAuth/players/` в формате JSON:
```json
{
  "username": "Player",
  "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "password_hash": "sha256_hash",
  "salt": "random_salt",
  "created_at": 1234567890,
  "last_login": 1234567890,
  "failed_attempts": 0,
  "locked_until": 0
}
```

## Логирование

В консоль логируются:
- ✅ Регистрация игроков
- ✅ Успешная авторизация
- ⚠️ Неудачные попытки входа
- ⚠️ Блокировки аккаунтов
- 🔧 Административные действия

**Пароли никогда не логируются!**

## Архитектура

```
ServerAuthPlugin (главный класс)
├── AuthManager (основная логика)
├── StorageManager (хранение данных)
├── ConfigManager (конфигурация)
├── MessageManager (сообщения)
├── PasswordManager (хеширование)
├── Commands
│   ├── RegisterCommand
│   ├── LoginCommand
│   ├── ChangePasswordCommand
│   └── AuthCommand
└── Listeners
    ├── AuthListener (подключение)
    ├── QuitListener (выход)
    ├── MoveListener (движение)
    ├── InteractListener (блоки)
    ├── DamageListener (урон)
    ├── CommandListener (команды)
    └── DropListener (предметы)
```

## Дизайн-система

Все сообщения используют единую дизайн-систему:
- **Тёмно-серый (§8)** - рамки, служебные элементы
- **Золотой (§6)** - акценты, важные элементы
- **Белый (§f)** - основной текст
- **Зелёный (§a)** - успешные операции
- **Красный (§c)** - ошибки
- **Жёлтый (§e)** - предупреждения

## Примеры сообщений

```
§8[§6Server§8] §fДля регистрации используйте:
§6/register <пароль> <повтор>

§8[§6Server§8] §aРегистрация успешно завершена.

§8[§6Server§8] §cНеверный пароль.
```

## Расширение

Плагин легко расширяется благодаря модульной архитектуре:
- Добавление новых команд через создание класса Command
- Добавление новой защиты через создание Listener
- Кастомизация сообщений через messages.yml
- Настройка поведения через config.yml
