# ServerAuth - Полноценная система регистрации и авторизации для PocketMine-MP

## 📋 Описание

ServerAuth - это production-ready плагин для PocketMine-MP (MCPE 1.1.5), обеспечивающий полную защиту аккаунтов игроков через систему регистрации и авторизации.

## ✨ Основные возможности

### Для игроков:
- **Регистрация** - `/register <пароль> <повтор>`
- **Вход** - `/login <пароль>`
- **Смена пароля** - `/changepassword <старый> <новый>`
- **Авто-вход** после регистрации (не нужно вводить `/login` отдельно)
- **Приветственные сообщения** при каждом входе на сервер

### Для администраторов:
- **Перезагрузка конфигурации** - `/auth reload`
- **Удаление аккаунта** - `/auth unregister <игрок>`
- **Информация об игроке** - `/auth info <игрок>`

### Безопасность:
- SHA-256 хеширование паролей с уникальной солью
- Защита от перебора паролей (максимум 5 попыток)
- Временная блокировка после превышения попыток (5 минут)
- Cooldown между попытками входа (3 секунды)
- Проверка длины пароля (4-20 символов)
- Пароли никогда не логируются и не отображаются

### Защита до авторизации:
- ✅ Блокировка движения
- ✅ Блокировка взаимодействия с блоками
- ✅ Блокировка получения/нанесения урона
- ✅ Блокировка дропа предметов
- ✅ Блокировка большинства команд

## 🚀 Установка

### Способ 1: Ручная установка
1. Скопируйте папку `ServerAuth` в папку `plugins/` вашего сервера
2. Перезапустите сервер
3. Настройте `config.yml` и `messages.yml` по необходимости

### Способ 2: Сборка .phar файла
```bash
php build.php
```
Поместите полученный `ServerAuth.phar` в папку `plugins/`

## ⚙️ Настройка

### config.yml - Основные настройки

```yaml
# Префикс сообщений
prefix: "§8[§6Server§8]"

# Безопасность
security:
  min-password-length: 4      # Минимальная длина пароля
  max-password-length: 20     # Максимальная длина пароля
  max-login-attempts: 5       # Максимум попыток входа
  lockout-time: 300           # Время блокировки (сек)
  login-cooldown: 3           # Cooldown между попытками (сек)
  auto-login-after-register: true  # Авто-вход после регистрации

# Защита до авторизации
protection:
  block-movement: true        # Блокировать движение
  block-block-interaction: true  # Блокировать блоки
  block-damage: true          # Блокировать урон
  block-drop: true            # Блокировать дроп
  block-commands: true        # Блокировать команды
  allowed-commands:           # Разрешенные команды
    - login
    - register
    - changepassword
    - auth
    - help

# Хранилище
storage:
  type: json                  # Тип хранилища
  players-folder: players     # Папка для данных
  auto-save-interval: 60      # Автосохранение (сек)
```

### messages.yml - Сообщения

Все сообщения используют единый дизайн:
- `§8` - тёмно-серый (рамки, служебные элементы)
- `§6` - золотой (акценты, имена)
- `§f` - белый (основной текст)
- `§a` - зелёный (успех)
- `§c` - красный (ошибки)
- `§e` - жёлтый (предупреждения)

## 📝 Команды

| Команда | Описание | Permission |
|---------|----------|------------|
| `/register <пароль> <повтор>` | Регистрация нового аккаунта | - |
| `/login <пароль>` | Вход в аккаунт | - |
| `/changepassword <старый> <новый>` | Смена пароля | - |
| `/auth reload` | Перезагрузка конфигурации | serverauth.reload |
| `/auth unregister <игрок>` | Удаление аккаунта | serverauth.unregister |
| `/auth info <игрок>` | Информация об игроке | serverauth.info |

## 🔐 Permissions

| Permission | Описание | По умолчанию |
|------------|----------|--------------|
| `serverauth.admin` | Полный доступ к админ-командам | op |
| `serverauth.reload` | Перезагрузка конфигурации | op |
| `serverauth.unregister` | Удаление аккаунтов | op |
| `serverauth.info` | Просмотр информации | op |
| `serverauth.bypass` | Обход авторизации | false |

## 💾 Хранение данных

Данные игроков хранятся в формате JSON:
```
plugins/ServerAuth/players/<имя_игрока>.json
```

Пример файла данных:
```json
{
  "name": "PlayerName",
  "uuid": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "password": "hash:salt",
  "ip": "127.0.0.1",
  "first_login": 1234567890,
  "last_login": 1234567890
}
```

## 🎯 Состояния игрока

1. **UNREGISTERED** (0) - Игрок не зарегистрирован
2. **REGISTERED_NOT_LOGGED** (1) - Зарегистрирован, но не вошел
3. **LOGGED_IN** (2) - Авторизован (полный доступ)

## 📊 Логирование

Плагин логирует следующие события (настраивается в config.yml):
- ✅ Регистрацию игроков
- ✅ Успешные входы
- ✅ Неудачные попытки входа
- ✅ Блокировки после превышения попыток
- ✅ Административные действия

Пароли **НИКОГДА** не логируются!

## 🛠️ Архитектура

Плагин использует архитектуру с разделением ответственности:

- **ServerAuthPlugin** - главный класс, инициализация
- **AuthManager** - основная логика авторизации
- **MessageManager** - управление сообщениями и локализация
- **StorageManager** - работа с хранилищем данных
- **Listeners** - обработка событий сервера
- **Tasks** - фоновые задачи (автосохранение)

Dependency Injection используется для передачи зависимостей между классами.
